OTTO TRAINING TRACKER – iPhone PWA

Tämä on kotinäytölle asennettava verkkosovellus, ei App Store IPA.

Käyttöönotto:
1. Julkaise kansion sisältö HTTPS-palvelussa (esim. GitHub Pages).
2. Avaa julkaistu HTTPS-osoite iPhonen Safarissa.
3. Jaa → Lisää Koti-valikkoon.

Sovellus sisältää 12 viikon ohjelman, penkin kerran viikossa, muiden liikkeiden progressiomallin, treenimerkinnät ja JSON-varmuuskopion. Data tallentuu selaimen paikalliseen tallennustilaan. Vie varmuuskopio säännöllisesti.

Laitteiden ja taljojen painot vaihtelevat saleittain. Reiden koukistus/ojennus ja ylätalja/face pull kalibroidaan käyttäjän omalla aloituspainolla. Trap bar -veto alkaa kevyenä nopeusharjoitteena.
